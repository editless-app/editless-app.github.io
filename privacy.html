プライバシーポリシー

制定日: 2026年11月2日

Editless 営業担当(以下「当方」)は、AI動画編集「Editless」のご案内にあたり、以下のとおり個人情報を取り扱います。

1. 取得する情報

  • お問い合わせやご返信の際にいただく、お名前、メールアドレス、チャンネル名・会社名、ご相談内容
  • ご案内メールへの返信の有無、ご相談(Google Meet)の日時
  • 当ページをどのリンクから閲覧されたかを示す識別子(URL のパラメータ。個人を特定するものではありません)

2. 利用目的

  • Editless に関するご案内、試算のご提示、ご相談日程の調整
  • お問い合わせ状況の管理
  • ご購入を希望される場合の、Editless 開発元へのご紹介(ご本人の了承を得たうえで、お名前・メールアドレス・チャンネル名をお伝えします)

3. Google サービスの利用について

当方は、ご案内メールの送信と返信の確認に Google の Gmail API を利用します。この API で取り扱うのは当方自身の送信用アカウントのメールのみで、お客様の Google アカウントのデータにアクセスすることはありません。Google API から取得した情報の利用は、Google API サービスのユーザーデータに関するポリシー(限定的な使用の要件を含む)に従います。

4. 第三者への提供

前記 2 の開発元へのご紹介を除き、法令に基づく場合を除いて、取得した情報を第三者に提供しません。

5. 保管と削除

取得した情報は、ご案内とお問い合わせ対応に必要な期間保管し、ご本人から削除のお申し出があった場合は速やかに削除します。

6. 配信停止

ご案内メールが不要な場合は、お届けしたメールに「配信停止」とご返信ください。以後一切ご連絡いたしません。

7. お問い合わせ

本ポリシーに関するお問い合わせは editless.app@gmail.com までお願いします。
